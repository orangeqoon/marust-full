トークンを入れる

下の手順で取ったトークンを貼って「保存」。金庫に入り、画面には出ません。トークンは AI やチャットに貼らず、この欄にだけ入れてください。

Picarto の題名を変えられるようにするには（トークンの取り方）
  1. アプリを登録する: を開き「Add client」。
    • Client Name・Client Description: 何でもよい（例: Title Updater）
    • Redirect URIs: をそのまま（1 文字でも違うと失敗します）
    • PKCE: Yes のまま →「Add Client」
    一覧に出た Client ID を控えます（Client Secret が出たときはそれも。どちらもトークンではありません）。
  2. 許可を出す: を開き、右上の「Authorize」。Client ID（あれば Client Secret も）を入れ、scopes は readpriv と write だけに印をつけて「Authorize」。Picarto のログインと許可の画面で許可します。sudo には印をつけないでください（お金のかかる操作まで許してしまいます）。
  3. トークンを読む: 同じページの「GET /user」→「Try it out」→「Execute」。下に出る curl の行の Authorization: Bearer の後ろの長い文字列がトークンです。
  4. そのトークンを上の欄に貼って「保存」。上の「設定」が「あり」になれば完了です。

送れなくなったら（トークンが切れた・取り消した）、2〜4 をやり直します。アプリの登録（1）はそのままで使えます。
