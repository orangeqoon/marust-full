はじめかた

丸ストは、OBS から複数の配信サイトへ同時に配信するときの、操作をまとめる道具です。映像そのものは OBS が送ります。丸ストを止めても、配信は止まりません。

はじめての配信（3 つの手順）

  1. OBS とつなぐ。OBS を起動し、メニューの「ツール → WebSocket サーバー設定」で「WebSocket サーバーを有効にする」にチェックを入れます。丸ストの最初の設定の案内に沿って、表示されたパスワードを入れます。
    （くわしくは OBS に丸ストの部品を入れる方法）
  2. サイトを足す。画面の「＋」を押し、サイトを選んで、配信の送り先（サーバー URL）と配信キーを貼ります。
    （どこにあるかは 配信キーの場所）
  3. 全部はじめる。「配信開始」を押すと、OBS の配信が始まり、足したサイトへ同時に送られます。終わるときは「配信停止（全部）」を押します。
サイトのボタンを押すと、そのサイトの設定（キーの入れ替え・題名・自動で枠を取る など）が開きます。ボタン自体は、止めるためのボタンではありません。

画面の細かさ（初級・中級・上級）

上のメニュー「表示」の「細かさ」で切り替えます。勝手には変わりません。慣れてきたら中級へどうぞ。

細かさどんな人向け見えるもの
初級（複数のサイトへ同時に配信）はじめて複数配信をする人配信開始・停止・サイトのボタン・「＋」だけ。配置は固定です。
中級（まとめて管理）毎日、複数のサイトで配信する人初級に加えて、サイトごとの開始・停止、通信の状況、ログイン、題名とカテゴリのまとめて反映、コメントの送信、「機能を足す」。
上級（作る・改良）自分で作る・改良したい人中級に加えて、配置の保存・接続端末・プラグインの管理（外から入れる・自分で作る）など。

困ったとき

  • OBS につながらない: OBS が起動していて、WebSocket サーバーが有効かを確かめます。パスワードも確かめます。
  • 「設定が足りない」と出る: そのサイトのボタンを押すと、足りない所がそのまま開きます。
  • ログインが切れた: 「ツール → 金庫（丸ストの鍵の保管場所）」から結び直します。1 つずつ順番に行ってください。
  • もっと見たい: メニュー「ヘルプ」から、最初の設定のやり直しや「この画面について」を開けます。
