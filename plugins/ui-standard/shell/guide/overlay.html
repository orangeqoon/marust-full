オーバーレイとは・OBS に取り込む方法

オーバーレイは、配信の映像の上に重ねて見せる小さな表示のことです。丸ストでは、タイマーの数字や今の題名、配信中のサイトの一覧を、OBS の画面に重ねて出せます。丸ストが「オーバーレイ」パネルで用意したウェブページのアドレス（URL）を、OBS の「ブラウザ」ソースに入れるだけです。3 分ほどで終わります。

丸ストは、OBS と同じパソコンで動いているときだけ、この URL が使えます。丸ストを起動したままにしてください（止めると、表示が止まります。配信そのものは OBS が出しているので止まりません）。

1. URL を用意する

  1. 丸ストの上のメニュー「表示」から「オーバーレイ」を開きます。
  2. 一覧に、使えるオーバーレイが並びます。それぞれに http://127.0.0.1:18770/overlay/… で始まる URL と「コピー」のボタンがあります。使いたいものの「コピー」を押します。
名前出るもの大きさの目安（幅 × 高さ）
タイマー / clockタイマーの数字と題名（背景は透明）600 × 200
基本オーバーレイ / title今の題名（背景は黒）1280 × 100
基本オーバーレイ / live-sites配信中のサイトの一覧（背景は黒）500 × 120

2. OBS に取り込む

  1. OBS を開き、下の「ソース」の「＋」を押して、「ブラウザ」を選びます。名前は自由です（例: 丸スト タイマー）。
  2. 設定の画面で、「ローカルファイル」のチェックは外したままにして、「URL」の欄に、さっきコピーした URL を貼り付けます。
  3. 「幅」と「高さ」に、上の表の大きさの目安を入れます（あとで変えられます）。
  4. 「OK」を押します。映像の上に表示が出ます。マウスでつかんで、好きな位置と大きさに動かします。

おすすめの設定: 「表示されていないときにソースをシャットダウン」はオフのままにしておくと、切り替えのたびに読み込み直さなくて済みます。

3. 見た目を変えたいとき

  • 黒い背景を消したい（題名・配信中のサイト）: ブラウザソースの設定の「カスタム CSS」に body { background: transparent !important; } と入れます。
  • 文字の大きさや色を変えたいときも、同じ「カスタム CSS」に書けます。

うまく出ないとき

  • 何も出ない・真っ白: 丸ストが起動しているか確かめてください。OBS のブラウザソースの「現在のページの再読み込み」を押すと直ることがあります。
  • URL が違うと言われる: URL は http://127.0.0.1:18770/overlay/ から始まります。丸ストの「オーバーレイ」パネルの「コピー」で貼り付けると間違えません。
  • 数字が動かない: タイマーのオーバーレイは、丸ストの「タイマー」で開始を押したときに動きます。
  • ほかのパソコンの OBS に出したい: 今の丸ストは、同じパソコン内の OBS だけを想定しています。
