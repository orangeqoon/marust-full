OBS に丸スト用プラグインを入れる方法

丸ストは、OBS に入れる専用のプラグイン（obs-multi-rtmp の丸スト用の版）を使って、複数のサイトへ同時に配信します。丸ストの初回の画面の「OBS にプラグインを入れる」ボタンを押すと、入ります（OBS を閉じてから）。ボタンを押さないかぎり、丸ストが自動で入れることはありません。ここは、手で入れたいときの手順です。5 分ほどです。

1. 用意するもの

  • Windows 版の OBS Studio（64 ビット）。
  • 丸スト用プラグインのファイル（obs-multi-rtmp.dll と、data\locale フォルダの 2 つの言語ファイル）。配布場所は、丸ストの配布ページ（GitHub Releases）です（一般公開の準備中）。作者から直接受け取った場合は、そのフォルダを使ってください。
すでに「obs-multi-rtmp」を入れている場合は、同じ名前のプラグインを上書きします。上書きする前に、今のフォルダを別の場所（デスクトップなど）にコピーして控えを取ってください。OBS のプラグインのフォルダの中に控えを置くと、二重に読み込まれて困ることがあります。

2. OBS を完全に閉じる

配信中なら先に配信を止めます。OBS を終了します（画面右下の通知領域に残っていないか確かめてください）。

3. プラグインのフォルダを開く

  1. エクスプローラーを開き、アドレス欄に次を貼り付けて Enter を押します。
    C:\ProgramData\obs-studio\plugins
    （ProgramData は隠しフォルダです。アドレス欄に貼り付ければ開けます。）
  2. obs-multi-rtmp というフォルダがあればその中へ、無ければ新しく obs-multi-rtmp フォルダを作ります。
  3. その中に bin フォルダ、さらにその中に 64bit フォルダがあることを確かめます（無ければ作ります）。

4. ファイルをコピーする

  1. obs-multi-rtmp.dll を C:\ProgramData\obs-studio\plugins\obs-multi-rtmp\bin\64bit\ へコピーします（古いものがあれば上書き）。管理者の確認が出たら許可します。
  2. data\locale フォルダの ja-JP.ini と en-US.ini を C:\ProgramData\obs-studio\plugins\obs-multi-rtmp\data\locale\ へコピーします。

5. OBS を起動して確かめる

  1. OBS を起動します。画面に、見慣れない赤い「非常停止」のボタンのような部品が出ることがあります（丸ストの非常停止です）。
  2. OBS のメニュー「ツール」→「WebSocket サーバー設定」で、「WebSocket サーバーを有効にする」にチェックを入れ、表示されるポートとパスワードを控えます。
  3. 丸ストの「OBS とつなぐ」（初回の案内の 1 つめ）にポートとパスワードを入れて「つないでみる」を押し、続けて「丸スト用の OBS プラグインの確認」の「確かめる」を押します。「入っています」と出れば完了です。

うまくいかないとき

  • 「入っていません」と出る: dll を置いた場所が違います。bin\64bit の中に直接 obs-multi-rtmp.dll があるか確かめ、OBS を再起動してください。
  • 「古いです」と出る: 丸スト用の新しい dll に入れ替えてください。
  • OBS が起動しない・おかしい: 控えを取ったフォルダを元の場所へ戻せば、元の状態に戻ります。
  • つながらない: OBS の「WebSocket サーバー設定」が有効か、ポートとパスワードが合っているかを確かめてください。
