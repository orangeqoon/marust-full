サイト別の困ったとき・直し方ガイド

丸ストでタイトル変更やコメント受信、ログインで問題が発生したときのサイト別対処法と復旧手順です。

FC2ライブ Kick YouTube Twitch ニコニコ生放送 ツイキャス SOOP Kukulu Picarto Rumble

FC2ライブ

Cookie 認証（拡張機能）

1. 「設定が取得できない」「settings-unavailable」「未設定」と表示される

原因: 丸スト内の Cookie（ログイン情報）が切れているか、最新情報が丸ストに届いていません。
  1. ブラウザ（Edge や Chrome）で、FC2のトップページではなく FC2 Live の配信管理ページ（https://live.fc2.com/）を開きます。
  2. ブラウザに入れた「丸スト拡張機能」が配信管理ページを検知し、最新の Cookie と配信情報を丸スト（127.0.0.1:18770）へ自動転送します。
  3. 自動転送されない場合は、ブラウザの右上ツールバーにある丸スト拡張機能アイコンをクリックし、「Cookie を今すぐ送信」を押してください。
  4. 転送完了後、丸ストの画面で再度タイトル変更をお試しください。
🌐 FC2 Live 配信管理画面を開く

2. 「コメントが待機のまま取得されない」

FC2 のコメント受信（chat-fc2）は、OBS で FC2 への配信が行われている間（配信中）のみ 動作する設計になっています。配信を開始すると自動で「待機」から受信状態へ切り替わります。

Kick

OAuth 2.1 認証

1. 「結び直したのにタイトル変更でエラー（500）になる」

原因: Kick サーバー側で一部のカテゴリ（I'm Only Sleeping などサーバー内部で不整合を起こす特定カテゴリ）を指定した際、Kick 側で Internal Server Error が発生します。
  1. カテゴリを「Just Chatting」や「Art」など一般的なカテゴリに変更して送信してみてください。
  2. 丸スト最新版では、Kick 側がカテゴリでエラーを返しても、配信タイトル単体で自動再試行（フォールバック）を行い、タイトルの更新を確実に成功させます。

2. 「ログインが切れた」「再認証（結び直し）したい」

  1. 丸ストのメニュー「サイト」またはタイトル変更パネルの「🔄 結び直す」ボタンを押します。
  2. ブラウザで Kick の認証画面が開くので、「Authorize」をクリックして認可してください。
  3. 自動的に丸ストに新しいトークンが保存され、画面に反映されます。

YouTube

Google OAuth 2.0

1. 「タイトルが変わらない」「unauthorized」

原因: Google 認証トークンの期限切れ、または配信枠（LiveBroadcast）が存在しない状態です。
  1. YouTube Studio（ライブ配信ダッシュボード）で配信枠が作成されているか確認します。
  2. 丸ストの「サイト」画面から YouTube の「結び直す」をクリックし、ブラウザで Google アカウントのログインを行ってください。

2. 「コメントが送信・取得できない」

YouTube のコメントは、YouTube 側で枠がアクティブ（配信中または公開枠）になって初めて LiveChatId が発行されます。配信を開始した後に自動で送受信が始まります。

Twitch

Helix OAuth 認証

1. 「カテゴリが見つからない・反映されない」

Twitch のカテゴリは Helix API の正式名称と一致している必要があります。入力欄で文字を入力すると候補（サジェスト）が出るので、候補一覧から選択して送信してください。

2. 「ログインを結び直す」

「サイト」画面から Twitch の「結び直す」を押すとブラウザで Twitch の承認画面が開きます。

ニコニコ生放送

Cookie 認証 ＋ 枠取り

1. 「ログイン情報がない」

ブラウザでニコニコ生放送にログインした状態で丸スト拡張機能から Cookie を送信するか、「ツール → 金庫」で設定します。

2. 「OBS 停止時の自動枠閉じについて」

丸ストでは誤操作や一時的な切断で枠が閉じてしまわないよう、OBS 停止後 60秒間（1分）待機 してから自動で番組を終了する安全ガードを設けています。1分以内に OBS 配信を再開した場合は枠閉じが自動キャンセルされます。

ツイキャス

OAuth / 配信キー

ツイキャスのタイトル・カテゴリ変更は API 経由で行われます。エラーが出る場合は「サイト」パネルでツイキャスの接続状態を確認してください。

SOOP

Cookie / トークン

ブラウザで SOOP にログインし、拡張機能から最新の Cookie を同期してください。

KukuluLive

Cookie 認証

kukulu.erinn.biz にログインした状態で Cookie を同期します。スリープ検知プラグインが待機と再接続を自動管理します。

Picarto

API トークン / 配信キー

Picarto のダッシュボードで発行した Bot/API トークンを金庫に登録して使用します。

Rumble

配信枠 / サーバーキー

Rumble の配信管理画面で発行した RTMP URL とキーを登録して使用します。
