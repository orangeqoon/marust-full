自分で機能を作る

丸ストの機能はプラグインという小さな部品でできています。自分用の部品を作って足すことができます。プログラムを書いたことがなくても、AI に頼んで作ってもらうやり方が一番かんたんです。

自分で作った（入れた）ものは自己責任です。プラグインは丸ストと同じ力で動きます。丸ストを守る壁はありません。何をするコードか分からないものは、動かさないでください。他人が作ったものは、信用できる配布元のものだけにしてください。

やり方 A: AI に作ってもらう（おすすめ）

  1. 丸ストの上級の画面で「プラグインの管理」を開き、「作る」の中の「AI に渡す依頼文をコピー」を押します。
  2. ChatGPT・Claude など、使っている AI のチャットに貼り付けて、続けて作りたい機能を日本語で書きます（例:「配信を始めたら、決まった文を自分のメモに記録する機能」）。
  3. AI が返したファイル（manifest.json と index.js など）を、下の「やり方 B」で作ったフォルダの中のファイルと入れ替えます。
  4. 丸ストの「プラグインの管理」で、そのプラグインの「試すだけにする」を押し、名前（id）を入力します。うまく動くか確かめてから、必要なら「有効にする」にします。

やり方 B: ひな形から作る

  1. 「プラグインの管理」の「作る」に、自分で決めた名前（id）を入れて「作る」を押します。id は小文字の英字・数字・ハイフンで 2〜32 文字、先頭は英字です（例: my-memo）。
  2. すでに同じ名前があるときは、何も作らずに止まります（上書きしません）。別の名前にしてください。
  3. できたら「フォルダを開く」を押します。manifest.json（名前・使う力の申告）、index.js（動き）、ui/（小さな画面）が入っています。メモ帳などで開いて書き換えます。
  4. 書き換えたら、プラグインの行の「無効にする」を押してから、もう一度「試すだけにする」（id の入力あり）を押すと、書き換えた内容で読み込み直されます。

作った直後は使っていない状態（legacy）です。動かすには、必ず名前（id）を自分で入力する確認を通ります。

外から入れるプラグインのきまり

項目きまり
manifestmanifestVersion: 2 と runtime: "inproc" だけ。
名前（id）小文字・数字・ハイフン、2〜32 文字。site- sink- slot- chat- で始まるもの、default・obs-engine・sites、丸ストが最初から持っている部品の名前は使えません。
秘密（キー・トークン）名前は ext.<自分のid>.… の形だけ。画面・ログ・戻り値には出さない。
配信全体の開始・停止使えません（obs.streamControl）。タイマーの開始終了とコメントの入り口の申告も使えません。
サイトの追加外からは入れられません。
置き場自分の id のフォルダだけ。ほかのフォルダは読めない作りにしてください。
動かし方入れた直後・作った直後は動きません。「試すだけ」「有効」にするとき、毎回 id を入力します。
配信中入れる・作る・戻す・消すは、配信中はできません。

「使う力」の一覧は作った人の申告であり、そこから外れた動きを丸ストが閉じ込めて止める仕組みではありません。

うまくいかないとき

  • 作れない（すでにある）: 同じ名前が使われています。別の名前にしてください。
  • 一覧に出ない: manifest.json の書き方が壊れていると読み込まれません。AI に「manifest.json を直して」と頼むか、いったん「作る」でひな形を作り直してください（別の名前で）。
  • 消したい: 行の「削除」を押します（すぐには消えず、1 つ前の版として残ります）。
