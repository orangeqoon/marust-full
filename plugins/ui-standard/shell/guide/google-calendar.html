Google カレンダーとつなぐ方法

丸ストのタイマーで測った時間を、Google カレンダーの予定として自動で残せます。つなぐには、あなた自身の Google の「鍵」（クライアント ID とクライアントシークレット）を 1 回だけ作って、丸ストに入れます。15 分ほどで終わります。お金はかかりません。

この鍵は、あなたのパソコンの丸ストの「金庫」にだけ保存されます。画面には出ません。人に見せないでください。

1. Google の鍵を作る（最初の 1 回だけ）

  1. Google Cloud Console を開き、カレンダーを使いたい Google アカウントでログインします。
  2. 上のプロジェクト選択から「新しいプロジェクト」を作ります（名前は自由。例: marust）。
  3. 左のメニューの「API とサービス」→「ライブラリ」で Google Calendar API を探し、「有効にする」を押します。
  4. 「API とサービス」→「OAuth 同意画面」（または「Google Auth Platform」）を開き、案内にそって作ります。ユーザーの種類は「外部」、アプリ名は自由、連絡先メールはあなたのアドレスです。
  5. 同意画面の「テストユーザー」に、あなた自身の Google アドレスを追加します。
  6. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」を選び、アプリケーションの種類は「デスクトップ アプリ」にします。作るとクライアント IDとクライアントシークレットが表示されます。

2. 丸ストに入れてログインする

  1. 丸ストの上のメニュー「ツール」→「タイマー」を開き、「Google カレンダーと連携」の欄に進みます。
  2. 「クライアント ID」と「クライアントシークレット」を貼り付けて、「保存してログインする」を押します。
  3. ブラウザで Google の画面が開きます。カレンダーを使うアカウントを選びます。「このアプリは Google で確認されていません」と出たら、「詳細」→「（アプリ名）に移動」を押します（あなた自身が作ったアプリなので安全です）。
  4. 「カレンダーの予定の表示・編集」を許可します。「認証が完了しました。このタブを閉じてください。」と出たら、丸ストに戻ります。
  5. 「タイマーの記録を Google カレンダーに残す」にチェックを入れると、記録が始まります。

つなぎ直しが必要になるとき

  • しばらく使わないと、ログインの期限が切れます。タイマー欄の「結び直す」（期限切れのときは「ログインする」）を押すと、ブラウザが開くので許可するだけです。鍵の入れ直しは要りません。
  • 同意画面が「テスト」のままだと、7 日で期限が切れることがあります。毎回つなぎ直したくないときは、同意画面の「公開ステータス」を「本番環境」に変えてください（自分だけで使う場合、Google の審査は要りません。「確認されていません」の表示が出るだけです）。
  • YouTube・Twitch・Kick も同じ「結び直す」を使います。結び直しは 1 つずつ順番に行ってください（同時に押すと、前のものが取り消されます）。

うまくいかないとき

  • 「redirect_uri_mismatch」と出る: クライアント ID を「ウェブ アプリケーション」で作っています。「デスクトップ アプリ」で作り直してください。
  • 「アクセスがブロックされました」と出る: 同意画面のテストユーザーに、ログインするアドレスが入っていません。手順 1 の 5 を確かめてください。
  • 認証用ポートが使用中: ほかのアプリがポート 3000 を使っています。閉じてからやり直してください。
  • 時間切れ: 3 分以内にブラウザで許可してください。もう一度ボタンを押せばやり直せます。
