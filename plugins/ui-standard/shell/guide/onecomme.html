わんコメの入れ方（コメントを受け取る）

丸ストは、コメントを受け取りません。受け取りは「わんコメ」に任せています。丸ストが行うのは、コメントの送信と、わんコメとの橋だけです。コメントを丸ストの画面で見たいときは、わんコメを入れて、丸ストにつなぎます。

  1. 公式サイトから入れる。わんコメのダウンロードページ（onecomme.com）から、自分の PC 用（Windows または macOS）を入れます。公式サイトのトップは onecomme.com、入れ方の説明は 導入ガイド です。
  2. わんコメを起動する。わんコメを開いたままにします（閉じるとコメントは来ません）。
  3. 丸ストにつなぐ。丸ストの「表示 → 細かさ」を上級にして「接続端末」を開き、「わんコメをつなぐ」を押します。出たコードを、わんコメ側の丸ストの連携の設定画面に入れます。
  4. つながったか見る。わんコメにコメントが来ると、丸ストの「コメント」の窓にも流れます。流れはじめると、「わんコメとまだつながっていません」の案内は消えます。
わんコメの入れ方・使い方は、わんコメ側の説明が正本です。画面の名前や手順は変わることがあります。丸ストはわんコメを自動で入れたり、自動で起動したりはしません。
