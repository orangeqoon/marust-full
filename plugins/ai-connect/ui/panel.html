AI をつなぐ

開発者モードのあいだは、ペアリングは要りません。AI（Claude など）は、そのまま丸ストを操作できます（承認も要りません）。

  • CLI: node cli/marust.js status や node cli/marust.js plugin reload <id>（npm run marust -- status でも同じ）
  • AI（MCP）: そのまま道具が出ます（起動し直しは要りません）

自動のつなぎは止まっています（今つながっている AI はそのまま使えます）。手でつなぐ（ペアリング）場合は、下のボタンでコードを出します。

手でペアリングする（リリース用・自動が切れているとき）
  1. 下のボタンを押すと、コードがここに大きく出ます（2 分で無効）。
  2. ターミナルで node cli/marust.js pair を実行して、このコードを入れます。
  3. AI 側（MCP）は node mcp/server.js pair で同じようにコードを入れます。
